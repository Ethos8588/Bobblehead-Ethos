# Shooting script

Film in this order, top to bottom, in **one continuous recording**.

**Between every take: stay still and silent for 3 full seconds.** Count them.
That silence is how `clip-splitter` finds the cuts. It will feel far too long. It is not.

Return to your idle pose between takes — that is what makes the crossfade look deliberate.

Fluffed a line? Pause 3 seconds and go again. Bad takes get deleted in the plan file.

---

### 01. `idle` — the looping clip

**Direction:** Sit still. Breathe. Blink. Small shift of weight halfway through. Look at the lens like you're waiting for someone to speak. 15 seconds, no talking.

**Says:** nothing.

## After filming

```
node split-recording.mjs my-recording.mp4
# check clips/clips.plan.json and the preview JPEGs, fix the names, then:
node split-recording.mjs my-recording.mp4 --cut --silent-first
```

Name the takes exactly as the `id` in each heading above — `idle`, `greeting_a`, and so on.
Then upload `clips/` and paste each URL into the matching `videoUrl` in `data/responses.json`.
